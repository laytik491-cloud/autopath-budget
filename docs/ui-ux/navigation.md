# Навигация MVP 1.0.0

Поездка → режим → результат на том же экране. Основной сценарий карты после настройки параметров: А → Б → построить. Ручной расчёт обновляется при вводе расстояния. Подробности — одно нажатие; возврат к полному пути — «Весь маршрут».

Справка содержит краткие инструкции использования. Запуск на устройствах перенесён в README. Очистка по-прежнему требует подтверждения в разделе «Расчёт».
