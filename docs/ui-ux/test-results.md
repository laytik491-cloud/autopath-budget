# Проверка интерфейса MVP 1.0.0

Пройдены 15 браузерных сценариев интерфейса, 6 длинного пути и 3 сетевого поведения/пути сайта. Отдельно проверены живая подписанная подложка на трёх масштабах, отсутствие значка флага и актуальные экраны. Полный [протокол](../mvp/test-results.md) и JSON в tests/results относятся только к MVP 1.0.0.
