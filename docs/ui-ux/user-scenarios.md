# Пользовательские сценарии 1.0.0

| Сценарий | Действия | Результат |
|---|---|---|
| Новая поездка без сети | По расстоянию, ввести 150 км | 12 л, 720 ₽, 180 ₽/чел. при 8/60/4 |
| Новый путь по карте | А, Б, построить | Расстояние и время сервиса, топливо и стоимость |
| Уточнение расхода или цены | Изменить поле | Пересчёт сразу без нового пути |
| Участники | Изменить число или +/− | Общая сумма прежняя, доля обновляется |
| Ошибка | Ввести 0 км, затем исправить | Ошибка поля, старый итог скрыт; корректный расчёт возвращается |
| Повторное открытие | Открыть тот же адрес и профиль | Последний сохранённый режим и корректные значения |
| Очистка | Расчёт, очистить, подтвердить | Черновик и журнал удалены атомарно |
