# Архитектура MVP 1.0.0

Схемы описывают браузерное приложение с Python в Web Worker, картой Leaflet и SQLite в IndexedDB. Основной поток и последовательность маршрута показывают режим карты. При ручном вводе calculate_manual получает километры без сетевых запросов. Суммы вычисляются общей функцией calculate_distance.

main.mjs связывает форму с worker.mjs; storage.mjs сохраняет образ SQLite. EventLog — обязанность Repository, отдельный объект не создаётся. Диаграммы показывают логические роли; соответствие реальным файлам приведено в разделе 23 пояснительной записки.
