# АвтоПуть Бюджет 1.0.0

Установочные файлы одной MVP для Windows, macOS и Android. Программа, Python и библиотеки расчёта входят в установщик. Python, Node.js и отдельный локальный сервер пользователю не нужны.

| Система | Файл | Установка |
|---|---|---|
| Windows 10 и 11, 64 бита | [AutoPath-Budget-1.0.0-win-x64.exe](https://github.com/laytik491-cloud/autopath-budget/releases/download/v1.0.0/AutoPath-Budget-1.0.0-win-x64.exe) | Откройте установщик и выберите папку. Ярлык появится в меню «Пуск» и на рабочем столе. |
| macOS 13 и новее, Apple Silicon и Intel | [AutoPath-Budget-1.0.0-mac-universal.dmg](https://github.com/laytik491-cloud/autopath-budget/releases/download/v1.0.0/AutoPath-Budget-1.0.0-mac-universal.dmg) | Откройте образ и перетащите «АвтоПуть Бюджет» в Applications. Затем откройте программу из Applications. |
| Android 12 и новее | [AutoPath-Budget-1.0.0-android.apk](https://github.com/laytik491-cloud/autopath-budget/releases/download/v1.0.0/AutoPath-Budget-1.0.0-android.apk) | Скопируйте APK на телефон и откройте. При запросе системы разрешите установку для приложения, из которого открыт файл. |

Для Android нужен актуальный Android System WebView. Windows ARM не входит в эту сборку. На Intel Mac используется код x64, на Mac с Apple Silicon — arm64; Rosetta для программы не нужна.

## Использование

По расстоянию: выберите режим и введите километры. При расходе 8 л/100 км, цене 60 ₽ и четырёх участниках 150 км дают 12 л, 720 ₽ всего и 180 ₽ на человека. Изменения применяются сразу.

По карте: выберите А, затем Б и нажмите «Построить маршрут». Для карты, поиска адресов и нового автомобильного пути нужен интернет. Ручной расчёт работает без сети, включая первый запуск установленных приложений.

Последний корректный расчёт сохраняется на устройстве. Установленные приложения имеют собственное хранилище; данные из прежней вкладки браузера автоматически не переносятся. При удалении приложения данные могут быть удалены средствами системы. Удаление Windows через стандартный деинсталлятор сохраняет папку пользовательских данных.

## Подпись

APK подписан локальным ключом выпуска. Mac-приложение имеет локальную подпись ad hoc; сертификата Apple Developer ID и нотариализации нет. EXE не имеет коммерческого сертификата издателя. Поэтому на другом устройстве система может запросить подтверждение запуска. Для доверенного Mac-приложения стандартный способ — «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» после первой попытки запуска.

## Исходники и проверка

Windows и macOS используют Electron, Android — Capacitor и системный WebView. Исходники и команды сборки находятся в [packaging](../packaging/README.md). Результаты испытаний и границы проверки находятся в [протоколе](../packaging/docs/ПРОВЕРКА.md).

Готовый APK рассчитан на Android 12 и новее. Совместимость с Android 10 в этом выпуске не реализована.

Файлы установщиков, общий архив и CHECKSUMS.sha256 размещаются в [выпуске 1.0.0](https://github.com/laytik491-cloud/autopath-budget/releases/tag/v1.0.0). Документация и база данных входят в репозиторий.
