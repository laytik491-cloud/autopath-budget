# Реализованные функции MVP 1.0.0

Программа рассчитывает топливо и стоимость по автомобильному маршруту либо введённым вручную километрам. Общая сумма делится между 1–9 участниками с учётом водителя. Ручной режим не требует точек, маршрутизатора или интернета и обновляет итог при вводе.

Карта использует OpenStreetMap с названиями стран, городов, населённых пунктов и улиц по масштабу. Начальный масштаб приближен к городу; цвет и контраст подложки сохранены. Подписи Leaflet и OpenStreetMap остаются без значка флага. Полный длинный путь и обе точки вписываются в карту. «Весь маршрут» возвращает полный вид; пересчёт цены сохраняет линию и масштаб.

Параметры проверяются на Python. Ошибочные значения скрывают итог и отмечаются у поля. Изменение точки отменяет актуальность пути. Поздние ответы не заменяют новые данные и ручной режим. Decimal и Fraction сохраняют промежуточную точность, вывод округляется half-up до двух знаков.

Один корректный расчёт записывается атомарно в SQLite через IndexedDB. В режиме карты используются draft, point и route, в ручном — manual_trip; event_log хранит не более 100 технических событий. При неверном вводе остаётся предыдущая корректная запись. При отказе записи видны ошибка и возможность повторить сохранение; успешная запись не сопровождается постоянной подписью.

Service Worker сохраняет 30 локальных ресурсов. После полной подготовки доступны новый ручной расчёт, сохранение и повторный запуск без сети в Chromium. Внешние тайлы, поиск и новый путь требуют интернета. Доступность определяется запросом; отдельного индикатора сети нет.

В интерфейсе три раздела: «Поездка», «Расчёт», «Справка». По карте основной процесс состоит из А, Б и построения; для ручного расчёта достаточно выбрать режим и поле. Справа внизу — OpenStreetMap, Photon и OSRM. Один логотип используется в шапке, вкладке и значках установки.

В корне репозитория находятся README, launch.py, app, database, docs, tests и .github. GitHub Actions запускает Python- и SQL-проверки; отдельный ручной workflow публикует только app. Публикация на GitHub в ходе подготовки не выполнялась.
