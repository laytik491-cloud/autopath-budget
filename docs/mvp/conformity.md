# Соответствие MVP 1.0.0 документации

Проверка относится к одному готовому комплекту. Описание согласовано с исходниками, SQL и фактическими результатами. Разделы 24–27 и ссылки на них исключены; действующие функции описаны в разделах 1–23.

| Область | Описание и реализация | Доказательство |
|---|---|---|
| Номер MVP | 1.0.0 в настройках, интерфейсе, кэше, коде, протоколах и документации | VERSION.txt, config.json, sw.js |
| Расход и стоимость | Общие точные формулы по метрам или ручным километрам; разделы 7–8, 23.3 | 58 Python-тестов; UI-01–03 |
| Без интернета | Новые ручные километры и сохранение; разделы 9.6, 16.12, 23 | UI-05–06, GH-03, INF-06 |
| Количество действий | А, Б, построить; ручной режим и поле; разделы 9 и 22 | UI-01, UI-07 |
| База данных | Пять таблиц; один корректный режим; раздел 21 | schema.sql; 26 SQL-проверок; INF-01–09 |
| Сохранение | Атомарная запись, защита последнего корректного расчёта; разделы 11, 21, 23.4 | UI-04, UI-13; INF-02–05,08 |
| Карта | Живая подложка с названиями по масштабу, без значка флага; разделы 10, 22, 23.8 | map-results.json; просмотр трёх масштабов |
| Длинный маршрут | Полная линия и обе точки, сохранение масштаба при цене | LR-01–06 |
| Интерфейс | Три раздела, чёрно-оранжевая тема, единый логотип, скрытые постоянные статусы успеха | UI-11–14; актуальные снимки |
| Запуск | Локальный launch.py, установка через HTTPS; README и раздел 23.7 | Проверка чистой папки |
| GitHub | README в корне; app, database, docs, tests, .github; относительные ссылки, Python и SQL в Actions | github-project-check.json |

Полный автономный запуск подтверждён в Chromium. Ограничение WebKit offline reload, отсутствие физических мобильных стендов и нагрузочных серий отражены в [границах проверки](known-limitations.md). Они не объявляются выполненными вариантами приёмочного плана.
