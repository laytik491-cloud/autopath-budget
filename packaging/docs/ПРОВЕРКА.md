Расчёт в установленных приложениях выполняет включённый Python через Pyodide. Интернет нужен для подложки, поиска и нового автомобильного пути. Проверки живого OSRM выполнены без подмены ответа сервиса.

Windows EXE собран на Mac и не запускался в Windows. Физические Android-телефоны, Intel Mac и все минимальные версии ОС отдельно не испытывались. Проверка Android относится к эмулятору и указанному WebView; проверка Mac — к Apple Silicon. iOS-пакет в этот комплект не входит.

Mac-приложение подписано ad hoc, без Apple Developer ID и нотариализации. Windows EXE не имеет сертификата издателя. APK подписан локальным ключом выпуска RSA 3072; подпись проверена через apksigner. Эти сведения отражены в README.

Машинные результаты включены в docs/verification. Контрольные суммы установщиков выдаются с готовыми пакетами в отдельном комплекте «УСТАНОВОЧНЫЕ ФАЙЛЫ». Ключ и пароль подписи не входят в комплект или исходники для GitHub.
